# Sender Mobile

تطبيق Android مستقل لإدارة العملاء وجهات الاتصال، مستوحى من احتياجات Sender Desktop دون تعديل مشروع سطح المكتب.

## إعداد المشروع
- Kotlin + Jetpack Compose
- Android 8.0 (API 26) كحد أدنى
- Compile/Target SDK 35
- Room لتخزين العملاء محليًا
- Google libphonenumber للتحقق من الأرقام وتوحيدها بصيغة E.164
- Apache POI كبداية لدعم ملفات Excel

## تصنيف أرقام العملاء
- الأرقام الدولية تُصنّف من مفتاح الدولة: مصر +20، الكويت +965، السعودية +966.
- الرقم المحلي الذي لا يبدأ بعلامة + يُفسّر افتراضيًا كرقم مصري.
- تُحفظ نسخة موحدة من الرقم لمنع تكرار العميل بصيغ كتابة مختلفة.
- الأرقام غير الصالحة لا تُحفظ.
- يمكن توسيع قائمة الدول لاحقًا دون تغيير قاعدة البيانات.

## البناء
يتطلب JDK 17 وAndroid SDK Platform 35. يمكن تشغيل البناء السحابي عبر GitHub Actions عند دفع التغييرات أو فتح Pull Request.

من مجلد المشروع:
`gradle assembleDebug`

> هذا تأسيس أولي للمشروع؛ واجهات الاستيراد وربط الأعمدة وسير العمل الكامل للحملات ستُستكمل على مراحل. لا يعتبر فتح تطبيق مراسلة دليلًا على نجاح إرسال الرسالة.
